서비스 소개

병원비를 확정하지 않고, 예상 범위를 설명합니다

MEDICost는 공개 수가와 비급여 자료를 일반인이 이해하기 쉬운 조건으로 묶어 예상 환자 부담 범위를 보여주는 참고용 도구입니다.

무엇을 돕나요

병원 등급, 진료 형태, 지역, 검사·시술·수술 항목과 실손보험 조건을 선택하면 공개자료 기준 예상 금액을 계산합니다.

의료 용어를 정확히 모르는 경우에도 질병명, 일반 표현, 초성이나 영문 약어로 항목을 찾을 수 있게 검색 기능을 제공합니다.

무엇을 보장하지 않나요

  • 병원이 발행하는 실제 견적서나 청구서가 아닙니다.
  • 진단, 치료 선택, 응급도 판단을 제공하지 않습니다.
  • 개별 보험사의 최종 보상 결정을 대신하지 않습니다.

이용 원칙

데이터 기준일과 출처를 화면에 표시하고, 계산 결과보다 한계와 변동 가능성을 함께 안내합니다.

서비스 분석은 동의한 경우에만 불러옵니다. 광고는 계산 입력·결과가 없는 정적 안내 페이지에만 표시합니다.

개인정보 처리 안내문의 안내

[필수] 프로토타입 선택 기능 데이터 수집 동의

선택 조건과 추가 검색은 기능 확장용 프로토타입입니다. 이 기능을 이용하려면 자체 방문·검색 통계 수집에 동의해야 합니다. 동의하지 않아도 필수 조건 기본 계산은 이용할 수 있습니다.

수집·이용 목적
프로토타입 선택 기능 제공, 미결과 항목 보완, 기능 확장 우선순위 결정, 동의 이용자의 방문 통계 집계
수집 항목
입력한 실제 검색어, 검색 결과 유무·횟수·시각, 무작위 브라우저 ID의 일간 해시, 페이지 조회 수
보유·이용 기간
수집일로부터 30일 후 자동 삭제
동의 거부
거부할 수 있습니다. 거부 시 필수 조건 기본 계산만 가능하고 프로토타입 선택 조건·추가 검색은 사용할 수 없습니다.
