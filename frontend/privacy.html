개인정보 처리 안내

프로토타입 선택 기능은 데이터 수집 동의가 필요합니다

필수 조건 기본 계산은 동의 없이 이용할 수 있습니다. 기능 확장용 선택 조건과 추가 검색은 아래 자체 방문·검색 통계 수집에 동의한 경우에만 이용할 수 있습니다.

프로토타입 선택 기능 필수 동의 항목

  • 목적: 프로토타입 선택 기능 제공, 미결과 항목 보완, 기능 확장 우선순위 결정, 동의 이용자의 방문 통계 집계
  • 항목: 공백과 대소문자를 정리한 실제 검색어, 검색 결과 유무·횟수·시각, 무작위 브라우저 ID의 일간 해시, 페이지 조회 수
  • 보유·이용 기간: 수집일로부터 30일

검색 로그에는 IP, 브라우저 식별자, 세션, User-Agent를 저장하지 않습니다. 방문 통계는 무작위 브라우저 ID를 날짜와 함께 해시한 값만 저장하며 검색 로그와 연결하는 키를 두지 않습니다.

이메일, 전화번호, 주민등록번호와 긴 숫자열은 저장 전에 거부합니다. 그 밖에도 이름, 환자번호, 진료기록처럼 개인을 식별할 수 있는 내용은 검색창에 입력하지 마세요.

동의 거부 권리와 이용 제한

개인정보 수집·이용 동의를 거부할 수 있습니다. 거부해도 병원 등급, 진료 형태와 비급여 기준 지역을 이용한 기본 계산은 가능합니다. 다만 검색, 치료·검사 항목 추가, 상병코드와 실손보험 등 선택 조건은 사용할 수 없으며 검색·방문 기록도 전송하지 않습니다.

브라우저에 저장하는 설정

localStorage에 `medicost-consent-v3` 이름으로 프로토타입 선택 기능 필수 동의 여부, 선택 사항인 Google Analytics 값과 변경 시각을 저장합니다. 자체 방문·검색 통계 수집에 동의하면 무작위 방문 식별자를 브라우저에 별도로 저장하고, 동의를 철회하면 이 식별자를 삭제합니다.

Kakao AdFit 광고

Kakao AdFit 광고 스크립트는 계산기 좌측·하단과 정적 안내 페이지에서 바로 불러옵니다. 입력칸과 예상 금액 숫자 위에는 광고를 겹치지 않습니다. 결과 보기 후에는 닫을 수 있는 제휴 안내를 띄울 수 있지만, 광고를 봐야만 결과가 열리는 방식은 사용하지 않습니다.

광고 제공과 품질 측정 과정에서 카카오가 익명화된 인터넷 사용정보, 쿠키 또는 유사 기술을 수집·활용할 수 있습니다. 자세한 처리와 거부 방법은 카카오 개인정보 정책과 사용 중인 브라우저의 쿠키 설정에서 확인할 수 있습니다.

쿠팡 파트너스

계산기 우측·하단과 정적 안내 페이지에는 화면 크기에 맞는 쿠팡 파트너스 다이나믹 배너를 둡니다. 배너를 불러오지 못하면 같은 제휴 추적코드가 적용된 일반 링크를 표시합니다. 제휴 링크를 통한 구매가 발생하면 일정액의 수수료를 받을 수 있으며, 구매자에게 추가 비용은 없습니다.

배너와 이동 과정에서 쿠팡이 쿠키 또는 유사 기술을 사용할 수 있습니다. 자세한 내용은 쿠팡 개인정보 처리방침에서 확인할 수 있습니다.

동의 변경·철회와 보유기간

메인과 공통 안내 페이지 하단의 “개인정보 설정”에서 프로토타입 선택 기능 필수 동의와 선택 사항인 Google Analytics를 각각 변경할 수 있습니다. 필수 동의를 철회하면 이후 검색·방문 통계 전송과 프로토타입 선택 기능을 중단합니다.

검색 로그와 날짜별 방문 통계는 수집일로부터 최대 30일 뒤 일일 삭제 작업에서 제거합니다. 검색과 방문 데이터를 연결하지 않으므로 이미 분리 저장된 방문 기록에서 특정 이용자 기록만 찾아 삭제할 수는 없습니다.

광고 쿠키는 브라우저 설정에서 차단하거나 삭제할 수 있습니다. 데이터 오류와 개인정보 문의 채널은 준비 중이며, 상업 공개 전 운영 주체와 공식 연락처를 이 페이지에 표시해야 합니다.

개인정보 처리 안내서비스 소개데이터 출처문의 안내

[필수] 프로토타입 선택 기능 데이터 수집 동의

선택 조건과 추가 검색은 기능 확장용 프로토타입입니다. 이 기능을 이용하려면 자체 방문·검색 통계 수집에 동의해야 합니다. 동의하지 않아도 필수 조건 기본 계산은 이용할 수 있습니다.

수집·이용 목적
프로토타입 선택 기능 제공, 미결과 항목 보완, 기능 확장 우선순위 결정, 동의 이용자의 방문 통계 집계
수집 항목
입력한 실제 검색어, 검색 결과 유무·횟수·시각, 무작위 브라우저 ID의 일간 해시, 페이지 조회 수
보유·이용 기간
수집일로부터 30일 후 자동 삭제
동의 거부
거부할 수 있습니다. 거부 시 필수 조건 기본 계산만 가능하고 프로토타입 선택 조건·추가 검색은 사용할 수 없습니다.
