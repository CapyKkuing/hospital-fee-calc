데이터 출처

계산에 사용한 자료를 숨기지 않습니다

화면의 기준일은 정적 데이터 파일에 기록된 날짜를 직접 읽어 표시합니다. 아래 자료는 예상 범위를 만드는 참고값이며 실제 청구 기준과 차이가 날 수 있습니다.

급여 수가

건강보험심사평가원의 의·치과 급여 수가 반영 내역을 정리한 정적 데이터셋을 사용합니다.

  • 파일의 sourceDate 값을 계산기 화면에 직접 표시
  • 코드·항목명·병원 종별 가격을 검색과 계산에 사용
  • 병원 등급별 가산과 본인부담률을 별도로 반영

비급여 가격

국민건강보험 비급여 항목별 가격정보 공개 화면에서 확인한 대표 항목과 프로젝트에 포함된 지역별 공개자료를 사용합니다.

  • 파일의 fetchedAt 값을 계산기 화면에 직접 표시
  • 지역 중앙값을 우선 사용하고, 없으면 평균값 또는 기존 추정값 사용
  • 병원별 실제 가격과 선택 항목에 따라 큰 차이가 날 수 있음

상병·진료 통계

2024년 공공데이터 CSV에서 만든 상병코드별 평균 진료비 통계를 참고합니다. 사용자가 검사·시술·수술을 직접 추가하지 않은 경우에만 평균값을 계산에 반영합니다.

업데이트와 한계

자료의 시행일과 수집일은 서로 다를 수 있습니다. 새 고시나 공개자료가 배포되어도 정적 파일이 갱신되기 전에는 이전 기준이 표시될 수 있습니다.

최종 비용 확인이 필요하면 방문할 병원과 가입한 보험사에 직접 문의하세요.

개인정보 처리 안내문의 안내

[필수] 프로토타입 선택 기능 데이터 수집 동의

선택 조건과 추가 검색은 기능 확장용 프로토타입입니다. 이 기능을 이용하려면 자체 방문·검색 통계 수집에 동의해야 합니다. 동의하지 않아도 필수 조건 기본 계산은 이용할 수 있습니다.

수집·이용 목적
프로토타입 선택 기능 제공, 미결과 항목 보완, 기능 확장 우선순위 결정, 동의 이용자의 방문 통계 집계
수집 항목
입력한 실제 검색어, 검색 결과 유무·횟수·시각, 무작위 브라우저 ID의 일간 해시, 페이지 조회 수
보유·이용 기간
수집일로부터 30일 후 자동 삭제
동의 거부
거부할 수 있습니다. 거부 시 필수 조건 기본 계산만 가능하고 프로토타입 선택 조건·추가 검색은 사용할 수 없습니다.
