## 관리자 통계 페이지 회귀 복구·영구 반영

- 목표: PC 계산기 폭 수정은 유지하면서 구형으로 돌아간 관리자 통계 화면을 최신 4탭 운영 화면으로 복구하고, 이후 Git 자동 배포에서도 다시 덮이지 않도록 원격 `main`에 영구 반영한다.
- 회귀 원인: 관리자 통계 최신판은 Production 직접 배포만 됐고 원격 Git에 저장되지 않아, 후속 PC 레이아웃 Git 배포가 구형 파일로 덮었다.
- 복구 기준: 이전 Production에서 자동 테스트·Pages 빌드·실제 Chrome·자산 해시까지 확인한 격리 릴리스 복사본이다.
- PC 계산기 `.calculator-workspace` 레이아웃과 관리자 `검색 운영` 4탭을 함께 보존한다.
- 운영 D1의 `visitor_daily_stats`는 이미 적용된 상태이며, 이번 복구에서 데이터 삭제·초기화·추가 migration은 하지 않는다.
